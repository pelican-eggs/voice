## Description

TS3 Manager is a simple and lightweight web-based interface for TeamSpeak 3.

Website: https://www.ts3.app/

## Server Ports

One port required to run the server.

| Port    | default |
|---------|---------|
| Game    | 3000    |

## Install notes

Connect with the IP of your node and the assigned port. Add your IP to your TS Server whitelist.
